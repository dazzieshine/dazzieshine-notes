# Веб-сайт - Доска Заметок - Учебное портфолио

Практическая работа №3 по дисциплине **«Веб-программирование»** (5 семестр).  
Проект представляет собой веб-сайт "Доска заметок" с возможностью создания, редактирования, удаления и перетаскивания стикеров (Drag & Drop) между панелью задач и рабочей областью.
